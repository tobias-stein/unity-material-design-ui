UI Telemetry Viewer

This service is a P0 placeholder for the local telemetry tool (session timeline + aggregate heatmaps). The actual viewer ships in phase P1 of ~/.opencode/plan/ui-telemetry-viewer.md.

What already exists against this tool:

  • The Unity runtime emits ui_snapshot_taken ledger points per written snapshot file (config: TelemetryConfig.snapshotLedger).
  • Reproducible test fixtures under Extra/telemetry-viewer/server/test/fixtures/ — regenerate with scripts/export-fixtures.sh, verify with scripts/export-fixtures.sh --check.

Session data lives in the InfluxDB service of this compose project (bucket ui), snapshot files in the app's persistentDataPath (default Telemetry/snapshots).
